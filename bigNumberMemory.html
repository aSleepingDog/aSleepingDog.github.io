高精度计算——1、应用

上次更新:2026-10-15
新闻中时常出现计算$\pi$的后续上千上亿位数，近年还求出了一个最大的梅森素数。这些数字的计算均使用到了高精度数字和相关计算算法。在民用领域，RSA加密算法也需要高精度数字。所以这个系列的文章将简单讲述一下高精度的相关表示、算法和应用。

使用时机

虽然高精度数字有很多应用领域，但是在很多情况下，基本数据类型提供的数字类型就已经够用。很多边界情况均可以加以限制来满足需求，简单的CPU指令要比调用内存快得多。所以请仔细斟酌是否需要高精度计算。

应用

高精度数使用较多的一般使用原码表示的自然数，这一类数有如下的操作。
按位非，按位或，按位与，按位异或，右移（丢弃低位），左移（可选溢出和不溢出），加法，减法，乘法，除法（一般向下取整），取余，比较

Python

Python自带的int类型本身就支持高精度，所以使用是最为简单的。需要注意的是解释器限制了int的最大值，如果需要计算则需要使用函数解除限制（但计算也更耗时）。而且int在多数情况下不可变，所以结果需要额外变量承接结果。 
a = 9876543210987654321

c = ~a
a += 1
a -= 1
c = a >> 1
a >>= 1
c = a << 1
a <<= 1

b = 1234567890123456789

c = a + b
c = a - b  # Python的整数默认是有符号的 相减可以无视大小
c = a * b
c = a // b # / 在Python中会将结果转换成IEEE754规定的浮点数 //才是上述提到的整数除法
c = a % b
c = a | b
c = a & b
c = a == b # < <= > >= != 同理

Java

Java的数学库中提供了高精度整数类BigInteger，由于其本身不可变（没有可供更改内部数据的函数），所以自加自减操作不支持。其余操作如下。 
import java.math.BigInteger;

public class test{
    public static void main(String[] args){
        BigInteger a = new BigInteger("9876543210987654321");
        
        BigInteger c = new BigInteger("0");

        c = a.not();             // ~a
        c = a.shiftLeft(1);   // a << 1
        c = a.shiftRight(1);  // a >> 1

        //不支持自加自减自移动

        BigInteger b = new BigInteger("1234567890123456789");

        c = a.add(b);       // a + b
        c = a.subtract(b);  // a - b
        c = a.multiply(b);  // a * b
        c = a.divide(b);    // a / b
        c = a.mod(b);       // a % b
        c = a.or(b);        // a | b
        c = a.and(b);       // a & b
        c = a.xor(b);       // a ^ b

        /*
            1 a > b
            0 a == b
            -1 a < b
         */
        int r = a.compareTo(b);
    }
}

JavaScript

JavaScript（ES11从2020.6开始，需要注意环境支持情况）内置对象BigInt，操作如下。 
let a = BigInt(1);
a = BigInt("9876543210987654321"); //通过函数定义
let b = 1234567890123456789n;      //通过后缀定义

//需要注意BigInt不能和原来的Number混用，必要时使用BigInt()函数进行转换
let c = ~a;
a += 1n;
a -= 1n;
c = a >> 1n;
a >>= 1n;
c = a << 1n;
a <<= 1n;

c = a + b;
c = a - b;
c = a * b;
c = a / b;
c = a % b;
c = a | b;
c = a & b;
c = a ^ b;
c = a == b;//< <= > >= != 同理

C++

C++的标准库STL至今没有高精度数支持，标准只支持最高64位的原码计算（gcc/llvm有128位的支持）。此处需要使用GUN项目下的GMP库提供的C++接口进行计算（详细内容会在后续更新）
