C++——Windows系统GCC-Mingw编译（零）

上次更新:2026-10-21
在安装完Mingw下的GCC编译器后，要完成第一次编译，这样能判断安装编译器是否正常工作，跑通第一个编译流程

设置环境变量

Windows系统提供了环境变量，作为程序运行时的查找的依赖和需要使用的变量。使用GCC开发程序时，需要加载一些内置的动态链接库。所以需要把必要的环境添加到环境变量中
复制编译器所在目录路径（末尾通常是bin）（有很多方式复制目录路径，如果此方案不可行，可以查询其他方案）
在开始菜单中搜索“环境变量”（有很多方式打开”环境变量“窗口，如果此方案不可行，可以查询其他方案）
按顺序依次单击打开，并粘贴目录，依次单击确认
在开始菜单中搜索“cmd”并单击打开
输入下列命令（如果你的cmd窗口整体看下来比较平滑和图片不太一致，这是正常的。示例中的windows是精简过的版本，所以cmd比较过时。但是这不影响结果） 
g++.exe --version
如果输出信息，则环境变量设置完成（具体信息可以因为来源而不固定，示例使用的是MSYS2提供的工具链）

手动编译

接下来的步骤将完成一次手动编译过程，测试编译器的可用性
在一个目录下新建文本文档（在空白处右键然后依次点击）
在第二排菜单栏（新建，一堆按钮，排序，查看）选择查看-显示-勾选文件扩展名。否则无法进行下方的重命名操作
右键将其重命名为 test.cpp，并忽略系统的警告（如果系统没有警告则上一步勾选文件扩展名的操作没有设置成功）
右键选择使用记事本打开
将下列代码复制粘贴到记事本（代码的细微差别不影响结果，直接选择复制即可）
并保存（可以同时按下Ctrl+S保存，也可以选择文件-保存的操作来保存） 
#include <iostream>
#include <string>
int main()
{
    std::string a;                               //声明字符串变量a
    std::cout << "hello world" << std::endl;     //输出字符串
    std::cin >> a;                               //输入非空字符串
    return 0;
}
如果选择先粘贴代码，再重命名也可以，不影响结果
在此目录的路径栏处输入cmd（确保此目录下没有叫做cmd的文件，文件夹或目录）呼出cmd窗口
依次输入下列命令（中间应该没有任何报错，无论是输出还是弹窗） 
g++.exe test.cpp -o test.exe
test.exe
如果显示出hello world，则继续输入任意字符并按下enter继续程序（或者同时按下Ctrl+C退出）
在上述输入命令，显示字符和输入字符（直接退出也行）的过程中，如果没有输出额外信息或弹窗，则说明GCC编译器已经能够正常使用了。
