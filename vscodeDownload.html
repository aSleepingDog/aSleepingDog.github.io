vscode下载安装

上次更新:2026-10-23
vscode（visual studio code 官网）是微软在2017年基于跨平台electron框架编写的跨平台代码编辑器，配合各种插件生态，可以进行几乎所有的编程语言的开发。是广泛使用的开发工具。
本篇文章将下载安装vscode（虽然现在都是傻瓜式了）

下载

点击中间的download键跳转至下载界面
下载的安装包

安装

双击运行，观看（应该会看吧）并选择同意协议后选择下一步
选择安装位置
选择开始菜单选项
选择额外操作（为了后续更好的体验，可以全部勾选，如果菜单过长可以考虑精简）
是否加入github copilot ai工具助手（微软在vscode内置的ai agent，不过在大陆因为网络问题经常连接不上，这里选择不添加）
最后查看选择的选项
等待解压安装
到此选择完成结束安装

中文支持

考虑到中文社区的庞大基数，和广大社区成员较为欠缺的英文使用能力。菜单区域的中文语言包是非常有必要了，接下来会配置中文环境
不过众多的技术文档都会以英文为主，所以了解每个菜单对应的单词也是很有必要的。
打开vscode（可以在桌面，开始菜单或者安装位置打开程序）
选择左侧纵向菜单的第五项，在搜索框中输入Chinese，选择简体中文（选繁体我也不阻止你），点击安装
等待安装完成（其实下面的简介都有使用方式了，接下来只是照着来）
Ctrl+Shift+P打开中间顶部的命令菜单，输入display，选择Configure Display Language
选择中文（简体）
依照提示选择Restart重启
重启后菜单界面的汉化就完成了
